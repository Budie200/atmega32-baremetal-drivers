# ATmega32 Bare-Metal Drivers

## Overview
A custom bare-metal hardware abstraction layer (HAL) for the ATmega32 microcontroller. This repository currently features a Input/Output (DIO) driver written in C. The project currently strives to have/implement direct memory-mapped register manipulation, efficient bitwise operations, and clean software architecture.

## Hardware Targeted
*   **Microcontroller:** ATmega32 
*   **Language:** C
